# موقع جمعية المجد الشبابية

الصفحة الرئيسية (Landing Page) لجمعية المجد الشبابية — حفر الباطن، مع مركز وثائق الحوكمة والشفافية.

## بنية المشروع

```
templates/index.html    الواجهة الرئيسية (ملف واحد متكامل: HTML + CSS + JS، خطوط مضمّنة)
static/fonts/           ملفات الخطوط (Cairo + Reem Kufi) لاستخدامها لاحقاً بدل التضمين
docs/site-spec.md       وثيقة مواصفات الموقع المرجعية
```

## أقسام الواجهة

- هيدر ثابت + قائمة جوال منزلقة + سلة تبرعات
- هيرو بنقش هندسي (نجمة ثمانية) + عدّادات إحصائية متحركة
- عن الجمعية (رؤية / رسالة / قيم)
- شبكة الخدمات الإلكترونية
- **مركز وثائق الحوكمة والشفافية** — تبويبات (أدلة الحوكمة، اللوائح والسياسات، محاضر الاجتماعات، التقارير السنوية، الشفافية المالية) وتحت كل تصنيف قائمة ملفات PDF مع أزرار معاينة وتحميل
- المشاريع والحالات مع فلترة (الكل / العاجلة / المكتملة) وأشرطة تقدّم
- بانر تبرع + البرامج + الأخبار + الشركاء + فوتر

## الهوية البصرية

| الرمز | القيمة | الاستخدام |
|---|---|---|
| `--brand` | `#5B4EA2` | البنفسجي الأساسي |
| `--teal` | `#59C7C1` | الفيروزي — لمسات وأيقونات |
| `--mint` | `#67C8A4` | الأخضر النعناعي |
| `--coral` | `#E95A5A` | المرجاني — أزرار التبرع |
| `--pink` | `#E95C7A` | الوردي |
| `--ink` | `#33323E` | الرمادي الغامق — النصوص |

الشعار الرسمي في `static/img/` (نسخة كاملة + أيقونة، بخلفية شفافة). الخطوط: **Reem Kufi** للعناوين، **Cairo** للنصوص. وايت مود ثابت.

## الخطوة القادمة — الباك اند (Flask)

- `app.py` + SQLite/PostgreSQL بنموذجين: `Section` (تصنيف الوثائق) و`Document` (الملف: عنوان، ملف PDF، تاريخ، عداد تنزيلات)
- لوحة تحكم لرفع الملفات تحت التصنيفات، وقسم الحوكمة في الواجهة يقرأ منها ديناميكياً
- تحويل الصفحة إلى قوالب Jinja وربط الخطوط من `static/fonts/`

> ملاحظة: الملفات والمحتوى المعروض حالياً تجريبي لغرض النموذج.
