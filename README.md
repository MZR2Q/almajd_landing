# موقع جمعية المجد الشبابية

الصفحة الرئيسية لجمعية المجد الشبابية — حفر الباطن، مع مركز وثائق الحوكمة والشفافية.

الموقع صفحة ثابتة بالكامل (بدون خادم أو قاعدة بيانات) — تعمل مباشرة على GitHub Pages أو أي استضافة.

## بنية المشروع

```
index.html            الموقع كامل (HTML + CSS + JS، الخطوط والشعار مضمّنة)
templates/index.html  نسخة مطابقة (للاستخدام مع أي إطار عمل لاحقاً)
static/fonts/         خطوط Cairo وReem Kufi
static/img/           الشعار الرسمي (كامل + أيقونة)
docs/site-spec.md     وثيقة مواصفات الموقع المرجعية
```

## مركز وثائق الحوكمة — كيف تُدار

كل الوثائق مصدرها **دكشنري واحد** اسمه `DOC_FOLDERS` داخل `<script>` في نهاية `index.html`،
وكل عنصر فيه اسم مجلد ورابطه على Google Drive:

```js
const DOC_FOLDERS = [
  {
    "name": "الجمعية العمومية",              // اسم التصنيف (يظهر كتبويب)
    "desc": "سجل الأعضاء ومحاضر الاجتماعات",  // وصف يظهر تحت العنوان
    "icon": "people",                        // الأيقونة
    "items": {
      "سجل أعضاء الجمعية العمومية المحدث": "https://drive.google.com/drive/folders/..."
    }
  }
]
```

- **لإضافة مجلد:** أضف سطر `"اسم المجلد": "الرابط"` داخل `items` للتصنيف المناسب.
- **لإضافة تصنيف:** انسخ كتلة `{ name, desc, icon, items }` كاملة وضعها في القائمة.
- **الأيقونات المتاحة:** `scale` `people` `board` `user` `doc` `money` `shield` `chart` `globe` `chat`

عدد المجلدات في كل تبويب يُحسب تلقائياً، ولا حاجة لأي تعديل في الـ HTML.

## الهوية البصرية

| الرمز | القيمة | الاستخدام |
|---|---|---|
| `--brand` | `#5B4EA2` | البنفسجي الأساسي |
| `--teal` | `#59C7C1` | الفيروزي — لمسات وأيقونات |
| `--mint` | `#67C8A4` | الأخضر النعناعي |
| `--coral` | `#E95A5A` | المرجاني — أزرار التبرع |
| `--ink` | `#33323E` | الرمادي الغامق — النصوص |

الخطوط: **Reem Kufi** للعناوين، **Cairo** للنصوص. وايت مود ثابت، RTL بالكامل.
