# موقع جمعية المجد الشبابية

الصفحة الرئيسية لجمعية المجد الشبابية — حفر الباطن، مع مركز وثائق الحوكمة والشفافية المُدار بلوحة تحكم (Flask + SQLite).

## التشغيل

```bash
pip install -r requirements.txt
python app.py
```

- **الموقع:** http://127.0.0.1:5000
- **لوحة التحكم:** http://127.0.0.1:5000/admin/ — كلمة المرور الافتراضية: `almajd2026`

> ⚠️ قبل النشر الفعلي غيّر كلمة المرور والمفتاح السري عبر متغيرات البيئة:
> `ADMIN_PASSWORD=...` و `SECRET_KEY=...`

## آلية عمل مركز الوثائق

- **التصنيفات** (أدلة الحوكمة، اللوائح والسياسات، محاضر الاجتماعات، التقارير السنوية، الشفافية المالية) تُنشأ تلقائياً أول تشغيل، ويمكن إضافة/تعديل/حذف تصنيفات من لوحة التحكم.
- **الملفات**: من لوحة التحكم ترفع ملفاً (PDF/Word/Excel/صورة) تحت أي تصنيف مع عنوان وتاريخ نشر، فيظهر مباشرة في قسم «الحوكمة والشفافية» بالصفحة الرئيسية مع زري معاينة وتحميل وعداد تنزيلات.
- الملفات تُخزن في `uploads/` وبياناتها في `instance/almajd.db` (SQLite).

## بنية المشروع

```
app.py                     خادم Flask: الصفحات + الرفع/التحميل + لوحة التحكم
templates/index.html       الواجهة الرئيسية (قسم الحوكمة ديناميكي من قاعدة البيانات)
templates/admin/           لوحة التحكم (دخول + إدارة التصنيفات والملفات)
static/fonts/              خطوط Cairo وReem Kufi
static/img/                الشعار الرسمي (كامل + أيقونة)
uploads/                   الملفات المرفوعة (خارج git)
instance/almajd.db         قاعدة البيانات (تُنشأ تلقائياً، خارج git)
index.html                 نسخة عرض ثابتة (GitHub Pages) ببيانات تجريبية
docs/site-spec.md          وثيقة مواصفات الموقع المرجعية
```
