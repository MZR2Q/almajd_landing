## 4) أقسام الصفحة الرئيسية (بالترتيب من الأعلى للأسفل)

1. **الهيدر:** شعار + زر "اتصل بنا 0530480670" + سلة التبرعات (بإجمالي بالريال) + حسابي الشخصي (تسجيل/دخول)
2. **سلايدر رئيسي** (صور بانر)
3. **نبذة عنا** (النص أعلاه)
4. **الخدمات الإلكترونية** — شبكة أيقونات: تبرعات المشاريع، تبرعات الحالات، المبادرات، الأخبار، مكتبة الصور، مكتبة الفيديو، البث المباشر، اللوائح والسياسات، المسابقات، اتصل بنا + زر "عرض المزيد"
5. **الحالات العاجلة** — بطاقات تبرع + تبويبات (كل الحالات / العاجلة / المكتملة)
6. **إنجازاتنا** — عدّادات أرقام: المستفيدين، الحالات، الأيتام، المشاريع
7. **المشاريع العاجلة** — بطاقات + تبويبات (الكل / عاجلة / مكتملة)
8. **البرامج العاجلة** — نفس البنية
9. **بانر دعوة للتبرع (CTA):** "تبرع الآن — ساهم بتبرعك لأحد المشاريع أو الحالات" + زرّان (تبرع المشاريع / تبرع الحالات)
10. **برامج الجمعية** — بطاقات تسجيل في البرامج
11. **آخر الأخبار**
12. **قالوا عنا** (التزكيات)
13. **المركز الإعلامي:** ألبوم الصور + ألبوم الفيديو + تضمين حساب تويتر/X
14. **شركاؤنا** (شعارات شركاء النجاح)
15. **الفوتر:** نبذة + الروابط السريعة + بيانات الاتصال + أيقونة X + حقوق النشر

- **نظام حسابات مستخدمين:** تسجيل، دخول، استعادة كلمة مرور، "تذكرني"، لوحة مستخدم (تبرعاتي، فرصي التطوعية، برامجي، حساب عضو الجمعية العمومية)
- **حاسبة/صفحة زكاة**
- **بوابة تطوع** (عرض فرص + طلب متطوعين)
- **بوابة وظائف**
- **بوابة جهات مستفيدة** (نموذجا تسجيل وطلب دعم)
- **نماذج تواصل متعددة:** راسلنا، اقتراح، شكوى، إبلاغ عن مخالفة
- **عدّادات إنجازات متحركة**
- **بث مباشر + مسابقات**
